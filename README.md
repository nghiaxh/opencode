# Opencode config

Global opencode configuration for commands and settings, see the [official docs](https://opencode.ai/v2/docs) for more detail.

## Install

```bash
cd ~/.config/opencode
git init
git remote add origin https://github.com/nghiaxh/opencode.git
git fetch origin
git reset --hard origin/main
```

## Update

Edit config directly at `~/.config/opencode/`, then run `/lazy-commit` to split the changes into conventional commits, and push:

```powershell
cd $HOME\.config\opencode
git push
```

## Structure

```
opencode.jsonc              # Server and project config
cli.json                    # Terminal client preferences, owned by the TUI
AGENTS.md                   # Always-on instructions, the only file auto-loaded
commands/lazy-ask.md       # /lazy-ask
commands/lazy-commit.md     # /lazy-commit
commands/lazy-audit.md      # /lazy-audit
commands/lazy-polish.md     # /lazy-polish
commands/lazy-test.md       # /lazy-test
skills/                     # Installed skills, gitignored
service.json                # Generated by the v2 service, gitignored
```

## Skills

Not tracked here. `npx skills add <repo> -s <name> -g -a opencode` installs into
`~/.config/opencode/skills`, which this repo gitignores. OpenCode discovers
that path plus `.opencode/skills` per project, so a fresh clone starts with no
skill installed.
