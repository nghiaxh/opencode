# Opencode config

Global opencode configuration for commands and settings.

## Skills

This repo tracks no skills. Every skill is installed with `npx skills` into
`~/.agents/skills/`, which OpenCode discovers automatically, so a fresh clone of
this repo starts with no skills at all.

```powershell
npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices -g -a opencode --copy -y
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -g -a opencode --copy -y
npx skills add vercel-labs/agent-skills --skill vercel-composition-patterns -g -a opencode --copy -y
npx skills add wshobson/agents --skill nextjs-app-router-patterns -g -a opencode --copy -y
npx skills add wshobson/agents --skill react-state-management -g -a opencode --copy -y
npx skills add wshobson/agents --skill accessibility-compliance -g -a opencode --copy -y
npx skills add wshobson/agents --skill typescript-advanced-types -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill javascript-typescript-jest -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill java-springboot -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill spring-boot-testing -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill create-spring-boot-java-project -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill javax-to-jakarta-migration -g -a opencode --copy -y
npx skills add github/awesome-copilot --skill sql-optimization -g -a opencode --copy -y
npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend -g -a opencode --copy -y
npx skills add https://github.com/Leonxlnx/taste-skill --skill minimalist-ui -g -a opencode --copy -y
```
