# Opencode config

Global opencode configuration for commands, skills, and settings.

## Install

```bash
cd ~/.config/opencode
git init
git remote add origin https://github.com/nghiaxh/opencode.git
git fetch origin
git reset --hard origin/main
```

## Update

Edit config directly at `~/.config/opencode/`, then commit and push:

```powershell
cd $HOME\.config\opencode
git add -A
git commit -m "chore: update config"
git push
```

## Structure

```
opencode.jsonc              # Server and project config
cli.json                    # Terminal client preferences, owned by the TUI
AGENTS.md                   # Always-on instructions, the only file auto-loaded
commands/lazy-commit.md     # /lazy-commit
commands/lazy-audit.md      # /lazy-audit
commands/lazy-review.md     # /lazy-review
commands/lazy-debt.md       # /lazy-debt
skills/taste-skill/         # Default design skill
skills/soft-skill/          # Agency-grade motion and visual depth
skills/minimalist-skill/    # Editorial, warm monochrome
skills/redesign-skill/      # Upgrade an existing UI
service.json                # Generated by the v2 service, gitignored
```

## Skills

Installed skills are plain markdown. OpenCode discovers them in two global
locations, later sources winning:

- `~/.config/opencode/skills/<id>/SKILL.md` (this repo, version controlled)
- `~/.agents/skills/<id>/SKILL.md` (installed by the CLI, not version controlled)

A skill's **ID** is its directory name. The frontmatter `name` is only a
display label, so `taste-skill` declares `name: design-taste-frontend` and is
loaded as `taste-skill`.

Installed from [skills.sh](https://skills.sh):

| ID | Source | Autoinvoke |
|---|---|---|
| `vercel-react-best-practices` | vercel-labs/agent-skills | yes |
| `java-springboot` | github/awesome-copilot | yes |
| `sql-optimization` | github/awesome-copilot | yes |
| `typescript-advanced-types` | wshobson/agents | no |

Install another:

```powershell
$env:DISABLE_TELEMETRY=1
npx skills add <owner/repo> --skill <name> -g -a opencode --copy -y
```

The CLI matches `--skill` against the frontmatter name, not the directory name,
and installs into `~/.agents/skills/`. Use `--copy`, symlinks break git
tracking. `npx skills update` refreshes those installs and reverts the
`opencode/autoinvoke: false` flag on `typescript-advanced-types`, so re-apply it
after an update.

Skills that overlap by topic are marked `opencode/autoinvoke: false` so only
one of them is advertised at a time. Three of the four design skills in this
repo enforce conflicting aesthetics on purpose, so stacking them produces
incoherent output. Load one by ID when a task actually has a visual component.

## Reload

- Command files and config reload on save, no restart needed.
- `AGENTS.md` edits are detected before the next model request and sent as an
  instruction update.
- Newly installed skills need a restart or a new session before they show up.
- Removing every `AGENTS.md` tells the session its previous instructions no
  longer apply.
